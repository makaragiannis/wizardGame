## Wizard Game

Just a silly Wizard game playable on Desktop, written in Java.

For feedback send me an email at marios.karagiannis.01@gmail.com

This is under development. There are multiple known bugs / issues. Some notable ones:
- Player can freely drop any card at the center even if they have already done so, or even if this card is not allowed to be played. This may cause bugs / crashes.
- The trump color when trump card is W is set randomly.
- I have barely worked on the styling. Some cards / menus may not fit the screen, especially if the hand contains many cards.
